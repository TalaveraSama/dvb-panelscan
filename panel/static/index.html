Newcamd (descifrado)

Verde brillante: al menos dos CW no nulas recientes en 15 s. Rojo: error o falta de ECM/CW reciente en un canal cifrado activo. Amarillo: esperando continuidad; azul: libre; gris: inactivo o sin telemetría. Solo se monitorizan los canales abiertos. Esto no certifica vídeo decodificado. Una conexión TCP correcta no confirma el login ni la recepción de CW. Verifica CAID, permisos de la tarjeta y los registros de OSCam.

Lista M3U8

Perfil pass: MPEG-TS sin transcodificar. No es HLS. El TS lo sirve tbsstream en /stream.ts (HTTP) y por UDP. La URL de cada canal apunta a un stream TS con ?profile=pass (estilo TVHeadend).

Sesiones compartidas · perfil pass

Multicanal: varios servicios del mismo transpondedor comparten una sola captura por adaptador. Transpondedores distintos requieren adaptadores distintos. El inicio manual fija solo ese canal; detenerlo no interrumpe los demás. Usa puerto 0 para las URLs del panel, o un puerto directo distinto por canal. Los clientes directos no se cuentan aquí. DISTRIBUCIÓN Y AUTORIZACIÓN

Flussonic

Dos conexiones independientes: Flussonic recibe las señales del panel y consulta al panel para autorizar espectadores.

1. Entrada de señales desde DVB Panel

Crea una cuenta técnica en Usuarios IPTV y descarga su M3U. Usa cada URL MPEG-TS como entrada HTTP en Flussonic. No uses una cuenta de cliente como fuente compartida.

2. Autorizar clientes desde el panel

Configura esta URL privada como on_play. No la entregues a clientes. Usa HTTPS/VPN y restringe el acceso desde el servidor Flussonic.

Usa este nombre exacto para que la autorización corresponda al canal seleccionado. El token del espectador se genera en Usuarios IPTV.

Respuesta del backend: 200 permite, 403 deniega; solicita revalidación cada 30 segundos. Sin límite de conexiones ni API Xtream Codes.

CONTROL DE ACCESO

Reproducción privada

VLC y otros clientes necesitan un token independiente del login. Quien tenga estos enlaces puede ver canales y EPG, pero no administrar el panel.

Generar otro token revoca los enlaces anteriores. No compartas estos enlaces públicamente. Utiliza HTTPS o una VPN; el token no cifra el tráfico.

Copia y guarda estos enlaces ahora. El servidor conserva únicamente el hash del token; no se puede volver a consultar.

Importar Astra / Cesbo

Importa TP, nombres/SID y perfiles. No importa usuarios, contraseñas de acceso al panel, permisos ni salidas HTTP/HLS/UDP. Detén los canales antes de previsualizar.

LNB universal 9750/10600. Confirma cada MAC → adaptador con el registro del kernel; no se deduce por el nombre. R no se convierte a V. Los TP deshabilitados se omiten. Conserva tu archivo original de forma privada.
